# 示例课程：一篇文章的标准写法

> **这篇文章是给你当模板用的。** 以后写新文章时，
> 把这份文件复制一份、改个名字（比如 `python-notes.md`），再替换里面的内容就行。

## 一、开头先写一句话摘要

用一行字说明这篇文章讲什么，读者三秒钟就知道要不要往下看。

---

## 二、正文用小标题分层

### 1. 一级小节用两个井号 `##`

正文直接写就行。换行要空一行，Markdown 才会分成两个段落。

### 2. 需要更细的分层，用三个井号 `###`

比如这里。

---

## 三、常用写法速查

**加粗** 用两个星号包起来，*斜体* 用一个星号包起来。

需要强调一句话时，可以这样写：

> 这是一段引用文字，左边会出现一条竖线。

### 无序清单

- 第一点
- 第二点
  - 想缩进就在前面多敲两个空格

### 有序清单

1. 第一步
2. 第二步
3. 第三步

### 插入链接

[点这里可以跳到课程首页](index.md)，或者写完整的网址 [百度](https://www.baidu.com)。

### 插入代码

一小段代码，用一对反引号包住，比如 `print("你好")`。

整块代码，用三个反引号起头结尾，并写上语言名：

```python
def hello(name):
    print(f"你好，{name}")

hello("世界")
```

### 插入表格

| 项目 | 说明 | 难度 |
| --- | --- | --- |
| Markdown | 写作语法 | 简单 |
| MkDocs | 生成网站 | 简单 |

### 插入提示框（这个主题特有，很好用）

!!! note "小提示"
    这里写提示内容。开头的 `!!! note` 表示"提示"，
    换成 `!!! tip` 是技巧，`!!! warning` 是警告，`!!! danger` 是危险。

---

## 四、结尾写点总结

文章最后可以说一句"这篇就到这里"，或者列出下次要讲的内容。
